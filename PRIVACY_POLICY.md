# Privacy Policy for Claude Exporter Pro

**Last Updated:** August 12, 2026

Claude Exporter Pro ("we", "our", or "extension") is committed to protecting your privacy. This Privacy Policy explains how our Chrome extension handles user data.

## 1. Zero Data Collection & Storage
Claude Exporter Pro operates **100% locally** within your web browser. 
- We do **NOT** collect, store, transmit, or monitor any personal data, conversation history, or user activity.
- All conversation data, extended thinking logs, code artifacts, and exported files remain entirely on your local device.
- We do **NOT** operate external servers, databases, or tracking analytics.

## 2. Chrome Extension Permissions Usage
Our extension requests only the minimum necessary permissions required to function:
- `storage`: Used solely to save user export settings (e.g. date format, page break toggles) locally via Chrome Sync.
- `activeTab`: Used to access the currently active Claude.ai tab when you initiate an export.
- `downloads`: Used to trigger local file downloads (PDF, Markdown, CSV, JSON, TXT) to your computer.
- `scripting`: Used to parse conversation content on Claude.ai when export is requested.
- `https://claude.ai/*`: Used strictly to read conversation turns and artifacts on Claude.ai web pages.

## 3. Third-Party Sharing & Remote Code
- We do **NOT** sell, trade, or transfer any user data to third parties.
- We do **NOT** execute remote code. All code is contained within the published extension package.
